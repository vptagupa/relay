Relay · v2 design

The terminal owns its history — not the shell.

A real, fully interactive shell — vim, top, REPLs and all — wrapped so Relay records every command as a structured, replayable block. Perfect save/restore, searchable history, and an agent chat that persists with the session — because the app is the source of truth, not the terminal's screen.

Real PTY · vim · top · REPLsCommand blocksLossless restoreFull-text searchPersisted agent chatRuns real Claude Code
The problem today

On Windows the OS pseudo-terminal (ConPTY) owns the screen and clears it whenever it repaints. Relay only mirrors that byte stream — so saved history flashes, clears, or restores imperfectly. We're always fighting the terminal for control.

What v2 does

Relay records the transcript itself and renders it. The shell stays fully interactive, but the history becomes data the app owns — so it can be saved, searched, exported, and restored exactly, with no flashing and nothing lost.

Everything it does

❯

Real interactive shell

A true PTY (PowerShell / bash / zsh). vim, top, less, ssh and node/python REPLs all work normally.

▦

Command blocks

Every command captured as a block: the command, its output, exit code, working dir, start time and duration.

⌄

Collapse & navigate

Fold long output; jump between commands from the outline rail; the current command stays pinned while its output scrolls.

⌕

Search & filter

Full-text search across the whole session — commands and output — with match highlighting. Filter to failures only, or by command.

⧉

Per-block actions

Copy the command, the output, or both. Re-run, pin/bookmark, or share any single block.

⤓

Lossless persistence

Exact save/restore across restarts and reboots — no flashing, nothing lost, because the transcript is data we own.

⇪

Export

Export a whole session — or a single block — to Markdown, JSON, plain text, or HTML.

✦

Persisted agent chat

Each terminal's AI chat is saved and restored, with agent-run commands linked to the blocks they produced.

⧗

Shell integration

Auto-injects OSC 133 prompt markers (PowerShell / bash / zsh) to delimit blocks and capture exit codes. Toggle in settings.

◧

Interactive-app markers

Full-screen sessions run live and are logged as markers you can see in the history — a dead process can't be resumed.
